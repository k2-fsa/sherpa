◆ phoneme_codepoints

std::vector<std::vector<int32_t> > sherpa_onnx::cxx::GenerationConfig::phoneme_codepoints

Pre-phonemized input as Unicode codepoints.

Phonemize the text yourself (for instance with piper_phonemize) and pass the resulting codepoints here. When set, it is used in place of the text argument. Leave empty to use text with a lexicon.

Each inner vector is one sentence.
