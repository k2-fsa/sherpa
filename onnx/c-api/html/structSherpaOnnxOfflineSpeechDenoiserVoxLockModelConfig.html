◆ voice_sample

const char* SherpaOnnxOfflineSpeechDenoiserVoxLockModelConfig::voice_sample

Optional. Path to a wave file with at least 3 seconds of the caller's voice. VoxLock keeps this voice and removes the others. From a longer file, it uses the loudest 3 seconds within the first 30 seconds. A file that is shorter or cannot be read is ignored, as if it were empty.

If empty or ignored, the voice sample is taken from the input audio:

  • Offline denoiser: the loudest 3 seconds in the first 15 seconds of the input are used.
  • Online denoiser: the audio is passed through unchanged until 3 seconds of speech have been heard; that speech is used as the voice sample.
