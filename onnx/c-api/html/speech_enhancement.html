Speech Enhancement / Denoising

sherpa-onnx supports both offline and online speech enhancement with three model families: GTCRN, DPDFNet and VoxLock.

See also
SherpaOnnxCreateOfflineSpeechDenoiser, SherpaOnnxCreateOnlineSpeechDenoiser

Offline GTCRN

SherpaOnnxOfflineSpeechDenoiserConfig config;
memset(&config, 0, sizeof(config));
config.model.gtcrn.model = "./gtcrn_simple.onnx";
config.model.num_threads = 1;
config.model.provider = "cpu";
const SherpaOnnxOfflineSpeechDenoiser *sd =
SherpaOnnxCreateOfflineSpeechDenoiser(&config);
const SherpaOnnxDenoisedAudio *denoised =
SherpaOnnxOfflineSpeechDenoiserRun(sd, wave->samples, wave->num_samples,
wave->sample_rate);
SherpaOnnxWriteWave(denoised->samples, denoised->n, denoised->sample_rate,
"./clean.wav");
SherpaOnnxDestroyDenoisedAudio(denoised);
SherpaOnnxDestroyOfflineSpeechDenoiser(sd);

Offline VoxLock

VoxLock is a target-speaker voice isolation model: it keeps the voice of one speaker (the caller) and removes the other voices. The model is from https://github.com/arbazsiddiqui/voxlock

SherpaOnnxOfflineSpeechDenoiserConfig config;
memset(&config, 0, sizeof(config));
config.model.voxlock.enroll_model = "./sherpa-onnx-voxlock-int8/enroll.onnx";
config.model.voxlock.chunk_model = "./sherpa-onnx-voxlock-int8/chunk_int8.onnx";
config.model.voxlock.voice_sample =
"./sherpa-onnx-voxlock-int8/test_wavs/en-voice-sample-f.wav"; /* optional */
config.model.num_threads = 1;
config.model.provider = "cpu";
const SherpaOnnxOfflineSpeechDenoiser *sd =
SherpaOnnxCreateOfflineSpeechDenoiser(&config);
// ... use sd ...
SherpaOnnxDestroyOfflineSpeechDenoiser(sd);

Model files: enroll.onnx and chunk.onnx (or chunk_int8.onnx) from https://github.com/k2-fsa/sherpa-onnx/releases/tag/speech-enhancement-models

voice_sample is optional: a wave file with at least 3 seconds of the caller's voice. From a longer file, the loudest 3 seconds within its first 30 seconds are used; a file that is shorter or cannot be read is ignored. If it is empty or ignored, the offline denoiser uses the loudest 3 seconds in the first 15 seconds of the input, and the online denoiser passes the audio through unchanged until 3 seconds of speech have been heard, then uses that speech.

Example source: speech-enhancement-voxlock-c-api.c, speech-enhancement-voxlock-with-voice-sample-c-api.c

Online GTCRN

SherpaOnnxOnlineSpeechDenoiserConfig config;
memset(&config, 0, sizeof(config));
config.model.gtcrn.model = "./gtcrn_simple.onnx";
config.model.num_threads = 1;
config.model.provider = "cpu";
const SherpaOnnxOnlineSpeechDenoiser *sd =
SherpaOnnxCreateOnlineSpeechDenoiser(&config);
int32_t frame_shift =
SherpaOnnxOnlineSpeechDenoiserGetFrameShiftInSamples(sd);
// Feed audio in frame_shift chunks, then flush
const SherpaOnnxDenoisedAudio *out = SherpaOnnxOnlineSpeechDenoiserFlush(sd);
SherpaOnnxDestroyDenoisedAudio(out);
SherpaOnnxDestroyOnlineSpeechDenoiser(sd);
