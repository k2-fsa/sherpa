const char* SherpaOnnxForcedAlignmentInterval::text

The text of this interval: the word for a word interval, the phone symbol for a phone interval. It is empty for a silence gap in the "words" tier (Praat interval tiers must tile the full time range, so the gaps between words are reported as intervals with empty text).
